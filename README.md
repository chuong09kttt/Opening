# AVEVA Equipment Studio

A professional web application for equipment dimension management with voice chat support.

## Features
- 📐 Equipment dimension input (Length, Width, Height, Radius)
- 📍 Position settings (E, N, U coordinates)
- 🧭 Orientation selection
- 🎤 Voice chat with speech recognition (supports English & Vietnamese)
- 📁 Output folder selection
- 💾 Generate configuration & Save as TXT
- 📱 Fully responsive design
